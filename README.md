## 🚀 Featured Projects

### 🏥 Ojas Raksha: DPDP-Compliant Blockchain Healthcare Consent Platform
Decentralized healthcare consent system with **10+ role-based dashboards** and on-chain grant/revoke access.
- AES-256 envelope encryption with a unique DEK per medical document, keys managed via **AWS KMS**
- Encrypted off-chain storage on **IPFS** with blockchain hash references
- Wallet-signature + nonce authentication; Solidity `grantConsent()`, `revokeConsent()`, `verifyAccess()`
- 📄 Provisional Patent Filed (2025) · Research paper under review (2026)

`React.js` `Node.js` `Solidity` `IPFS` `AWS KMS` `MetaMask` `Web3`

`React.js` `Tailwind CSS` `JavaScript` `Vercel` `GitHub Actions`
