### 🏥 Flagship Case Study: Ojas Raksha (Blockchain Healthcare Consent Platform)
*Provisional Patent Filed (2025) · Research Paper Under Review (2026)*

<div align="center">
  <a href="https://puneethmanojsai.vercel.app">
    <img src="assets/ojas-architecture.svg" width="100%" alt="Ojas Raksha Architecture: React dApp, Node.js API, Solidity Smart Contracts, IPFS & AWS KMS" />
  </a>
</div>

<br/>

<details open>
<summary><b>🔍 Deep Dive: Architecture & Engineering Highlights</b></summary>

- **10+ Role-Based Dashboards:** Granular access tiers for patients, doctors, hospitals, insurance providers, and diagnostics with real-time on-chain consent management.
- **Envelope Encryption Pipeline:** Client-side AES-256-GCM encryption with unique Data Encryption Keys (DEK) managed dynamically via **AWS Key Management Service (KMS)**.
- **Decentralized Storage:** Medical records stored encrypted on **IPFS (InterPlanetary File System)**, referencing immutable IPFS CIDs on Ethereum/EVM smart contracts.
- **Cryptographic Authentication:** Zero passwords — authenticated via MetaMask wallet signatures and cryptographic challenge-nonces.
- **Smart Contract Methods:** Solidity-based `grantConsent()`, `revokeConsent()`, and `verifyAccess()` executing transparent access control rules.
</details>
